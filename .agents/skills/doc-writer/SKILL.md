Technical writing for software projects. The core rules apply across document types; feature
references carry format-specific guidance. Current feature coverage focuses on README and
other Markdown files.

- Apply the Audience, Style, and Workflow references to every artifact
- Load only the feature reference that matches the requested artifact
- Follow repository conventions and pair with a format-specific skill when exact syntax applies

## Core

| Topic | Description | Reference |

| Audience | Constrains who each artifact or section serves and what belongs in its reading path | [core-audience](references/core-audience.md) |

| Workflow | Constrains how evidence is gathered, content is drafted or revised, and results are verified | [core-workflow](references/core-workflow.md) |
